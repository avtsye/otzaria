# דף הבית – תוסף דוגמה

תוסף מינימלי המדגים את `plugin.setNewTabPage`.

בעת טעינת התוסף הוא רושם את הדף שלו כיעד של כפתור `+`. עצם הצגת הכפתור נשלטת רק בהגדרות אוצריא; התוסף אינו מציג או מסתיר אותו. אם התוסף נסגר או מושבת, אוצריא מסירה את הרישום והכפתור חוזר לפתוח את הספרייה.

הדף כולל חיפוש ספרים בסיסי ופתיחת ספר מתוצאות החיפוש.
